# Comparison (criterion → option A → option B → verdict)

## When chosen

Several actors or approaches sit on one scale and the reader must choose.
Genres: industry, and research that pits methods.

## Skeleton

1. **Criteria.** Three to five hard axes, each with a scale.
2. **Matrix.** A table scoring every option on every axis.
3. **Verdict.** By fit, not by winner: «если вам нужен X, берите A; если Y,
   берите B».

## Blocks

- Criteria: each axis names how it is measured, on what period, from what
  source.
- Matrix: scannable, one row per option.
- Verdict: follows from the scale. No verdict without the table, no table
  without a scale.

## Failure modes

- «Обе стороны правы» with no verdict.
- A competitor named only to be dismissed.
- A criterion with no scale, so nothing is actually compared.
