# i18n — quick reference

**Bilingual: RU + EN**. Dictionaries are build-time only, never loaded at runtime.

## Key rules

- **Always both languages** — every new text ships in RU and EN simultaneously
- **Keys, never hardcoded** — components receive i18n keys and translate them
- **Missing translation = bug** — not a detail

## File structure

| What | Location |
|------|----------|
| UI copy | `src/shared/i18n/ru/<ns>.ts` + `src/shared/i18n/en/<ns>.ts` |
| Entity copy | `src/entities/<slice>/i18n/<plural>.ts` — per-entity files |
| Dictionary | `src/shared/i18n/dict.ts` — composes shared + entity dicts |
| Types | `typeof` — no `as const`, no recursive Widen |

## Per-entity files (recent change)

Each entity (`solutions`, `cases`, `services`) now has:
- `index.ts` — barrel, aggregates all entities into `entityRu`/`entityEn`
- `<slug>.ts` — one file per entity, e.g. `agentic-systems.ts`

**Benefit**: Adding a new entity = create one file + update index. Adding a language = create mirror files.

## Component pattern

```tsx
function Card({ lang }: { lang: AppLang }) {
  const t = useT(lang);
  return <p>{t("ui.readMore")}</p>;
}
```

Pass `lang` down only — no translator props.

## Parity check

`test/astro-content.test.ts` compares RU/EN key paths namespace by namespace. New namespace without English mirror fails the suite.

## Language switch

- Lives in `localStorage["lang"]`
- Reaches `<html lang>` via `BaseLayout` prop
- Toggle: `LanguageToggle` in AppBar
